# Comptabilité (téléphone)

Application installable pour le téléphone, reliée à l'application Comptabilité de l'ordinateur par Google Drive.

- S'ouvre et fonctionne **sans réseau** : livres, reçus photographiés, factures, devis, agenda, trajets et entretiens restent gardés dans le téléphone.
- Au retour du réseau, les ajouts partent tout seuls dans le dossier `Comptabilite/telephone` du Google Drive ; l'application de l'ordinateur les intègre.
- Aucune donnée n'est dans ce dépôt : il ne contient que le code de l'application.

Installation sur Android : ouvrir la page dans Chrome, puis **⋮ › Installer l'application**.
