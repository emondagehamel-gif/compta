        Exporter pour ton comptable

        Crée un seul fichier ZIP avec les pièces de la période, renommées par date, fournisseur ou client et montant, et une liste (index.csv) qui s'ouvre dans Excel. Le fichier est aussi enregistré dans le dossier exports.

        Factures à payer

        Fournisseurs

        À partir de 100 $ d'achat, les numéros de TPS et de TVQ du fournisseur doivent figurer sur le reçu pour que ta société récupère ces taxes. À partir de 500 $, la facture doit aussi porter le nom de ta société, une description et les modalités de paiement.

        Comptes

        Exporte ton relevé en format CSV depuis le site de ta banque, puis choisis le fichier. Les opérations déjà inscrites sont reconnues, et les nouvelles sont ajoutées à la liste « À vérifier ». Tu peux aussi envoyer le relevé à Claude dans la conversation : il le classera pour toi.

        Téléphone

        L'application du téléphone fonctionne même sans réseau. Elle envoie tes ajouts (reçus, rendez-vous, factures, trajets, entretiens) dans le dossier telephone, synchronisé par Google Drive, dès que le réseau revient. Cette application les intègre à tes livres dès qu'elle est ouverte, puis efface les fichiers reçus.

        Données

        Tes livres sont dans le fichier registre.json du dossier Comptabilite. Une copie est faite chaque jour dans le dossier sauvegardes. Copie le dossier sur une clé USB ou dans un nuage de temps en temps.
